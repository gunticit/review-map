# 📜 GitHub Policy - Laravel 11 Project
## 1. 🚀 General Rules
  All changes must go through a Pull Request and be reviewed before merging.
  Follow the PSR-12 coding standard to maintain clean and maintainable code.
  Always update README.md when making significant changes to the project.
## 2. 🔒 Branch Management
  main: Only contains thoroughly tested and stable code.
  develop: The main development branch where new features are merged.
  feature/*: Dedicated branches for individual features.
## 3. 🎯 Commit Rules
  Use clear commit messages:
  makefile
  Sao chép
  Chỉnh sửa
  feat: Add feature X  
  fix: Fix bug Y  
  refactor: Improve code Z  
  Do not commit .env files or any sensitive information.
## 4. 🔄 Review & Merge
  At least one team member must review before merging.
  No direct merging into main, only merge from develop.
  Check migrations and test cases before merging new code.
## 5. 🛠 Deployment & CI/CD
  Use GitHub Actions to check for syntax errors and run automated tests.
  Ensure .env.example is always updated with the latest changes.

# 📜 GitHub Policy - Laravel 11 Project
## 1. 🚀 Quy tắc chung
  Mọi thay đổi cần thông qua Pull Request và được review trước khi merge.
  Tuân thủ PSR-12 coding standard để đảm bảo code sạch và dễ bảo trì.
  Luôn cập nhật README.md khi có thay đổi quan trọng trong dự án.
## 2. 🔒 Quản lý nhánh (Branch Management)
  main: Chỉ chứa code đã được kiểm tra kỹ, ổn định.
  develop: Nhánh chính để phát triển, merge các tính năng mới vào đây.
  feature/*: Nhánh dành cho từng tính năng riêng biệt.
## 3. 🎯 Quy tắc commit
  Sử dụng cú pháp commit rõ ràng:
  makefile
  Sao chép
  Chỉnh sửa
  feat: Thêm chức năng X  
  fix: Sửa lỗi Y  
  refactor: Cải thiện code Z  
  Không commit file .env hoặc thông tin nhạy cảm.
## 4. 🔄 Review & Merge
  Ít nhất một thành viên phải review trước khi merge.
  Không merge trực tiếp vào main, chỉ merge từ develop.
  Kiểm tra lại migration, test cases trước khi merge code mới.
## 5. 🛠 Deployment & CI/CD
  Sử dụng GitHub Actions để kiểm tra lỗi cú pháp, chạy test tự động.
  Đảm bảo .env.example luôn được cập nhật đúng với các thay đổi mới.
